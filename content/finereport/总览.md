## 一、FineReport 基础与安装部署

### 1.1 产品概述
- **定位**：企业级 Web 报表工具，支持复杂报表、填报、大屏、移动端。
- **报表类型**：
  - 普通报表（.cpt）：类 Excel 设计，支持扩展、分组、交叉。
  - 聚合报表（.cpt）：不规则报表，通过聚合块拼接。
  - 决策报表（.frm）：可视化大屏/驾驶舱，组件化布局。
- **架构**：设计器（本地设计）+ 服务器（Web 应用）+ 数据库/数据源。
- **典型场景**：管理驾驶舱、经营分析、数据填报、移动报表、大屏可视化。

### 1.2 安装与部署
- **环境要求**：JDK 1.6+（建议 1.8）、Tomcat 6+、Windows/Linux。
- **部署方式**：
  - 独立部署：使用内置 Tomcat。
  - 集成部署：将 Web 工程放入 Tomcat、WebLogic、WebSphere、JBoss 等。
- **目录结构**：
  - `reportlets`：报表模板存放目录。
  - `resources`：图片、样式等资源。
  - `logs`：日志文件。
  - `WEB-INF/config`：核心配置（datasources.xml、log.xml、server.xml）。
- **配置文件**：
  - `datasources.xml`：数据源连接池配置。
  - `server.xml`：服务器端口、内存、字符集。
- **服务管理**：启动、停止、重启；Windows 服务注册；Linux 脚本。
- **升级与迁移**：版本升级需备份模板、配置、数据库；迁移注意授权文件。
- **授权注册**：导入 license 文件，激活模块。

### 1.3 设计器基础
- **界面**：菜单栏、工具栏、模板面板、数据集面板、属性面板、日志面板。
- **文件类型**：`.cpt`（普通/聚合）、`.frm`（决策报表）。
- **预览方式**：分页预览、填报预览、数据分析预览、移动端预览。
- **远程设计**：连接远程服务器，直接编辑服务器模板。
- **模板加密**：保护模板不被篡改。

> 相关：[[二、数据连接]]、[[四、报表设计核心]]、[[十一、系统管理与运维]]

## 三、数据集与数据准备

### 3.1 数据集类型
- 数据库查询、存储过程、内置、文件、SAP、多维数据库、程序、关联、树数据集。

### 3.2 数据库查询
- **SQL 编辑器**：语法高亮、多行编辑。
- **多表关联**：JOIN、子查询。
- **参数化查询**：使用 `where 字段 = '${参数}'`。
- **动态 SQL**：
  - `${}`：直接替换，存在 SQL 注入风险。
  - `#{}`：预编译参数，安全防注入。
- **预览**：查看数据集结果。
- **SQL 优化**：避免 `SELECT *`，建立索引，减少关联表。

### 3.3 存储过程数据集
- 调用数据库存储过程，传递输入参数，处理单/多结果集。

### 3.4 文件数据集
- **Excel**：支持 xls/xlsx，指定 sheet 和区域。
- **文本**：分隔符解析。
- **XML/JSON**：解析结构化数据。
- **远程文件**：通过 HTTP 获取文件，路径可参数化。

### 3.5 关联数据集
- 多数据集通过关联条件组合，支持内连接、左连接、右连接、全连接。

### 3.6 树数据集
- 构建父子层级，用于树控件、下拉树、组织架构展示。

### 3.7 程序数据集
- 实现 Java 接口，自定义数据读取逻辑，部署到服务器。

## 四、报表设计核心

### 4.1 报表设计基础
- 单元格命名（A1、B2）、行列操作、合并、边框、纸张与页面设置。

### 4.2 数据列与单元格扩展
- **扩展方向**：不扩展、纵向扩展、横向扩展。
- **父格设置**：左父格、上父格，控制扩展归属。
- **分组**：普通分组、相邻连续分组、自定义分组、条件分组。
- **汇总**：SUM、COUNT、AVG、MAX、MIN、VAR、STDEV。
- **累计**：逐层累计、跨层累计、条件累计。
- **占比与排名**：百分比、RANK。
- **层次坐标**：
  - 相对层次坐标：`A1[A2:1]` 表示取当前组内第一条。
  - 绝对层次坐标：`A1[!0]` 表示取全部。
  - 位移坐标：`A1[A2:-1]` 上一条。
- **数据过滤、排序、自定义值显示**。

### 4.3 单元格元素
- 文本、数据列、公式、富文本、图片、图表、子报表、二维码、条形码、斜线表头、控件。

### 4.4 单元格属性
- 字体、对齐、自动换行、缩进、边框背景、行高列宽、锁定、格式（数字/日期/货币/自定义）。

### 4.5 单元格形态
- **数据字典**：内置、公式、SQL、自定义。
- **公式形态**：动态显示内容。
- **金额大写**：数字转中文大写。
- **条形码/二维码形态**：生成条码、二维码。
- **自定义形态**：Java 类扩展。

### 4.6 条件属性
- **条件类型**：当前值、公式、行/列条件。
- **效果**：字体颜色、背景色、行高列宽、新值替换、控件切换、可见性、分页控制、打印/导出控制。
- **优先级**：从上到下依次匹配。

### 4.7 超级链接
- 类型：网络报表、网页、邮件、JavaScript、动态参数传递、下载、填报提交。
- 条件超链接：满足条件才显示链接。

### 4.8 分页与打印
- 分页设置：行分页、列分页、分页条件。
- 重复标题行/列、冻结行列、页面缩放。
- 页眉页脚、页码。
- 打印：区域、顺序、份数。
- 导出：PDF、Excel、Word、图片、HTML、CSV。

### 4.9 样式与主题
- 全局样式、预定义样式、样式继承、模板主题。

### 4.10 聚合报表设计
- 聚合块创建、大小位置调整，适合不规则报表。

## 使用说明（Obsidian 图谱构建）

1. **创建主笔记**：将本文件保存为 `FineReport 8.0 知识图谱.md`。
2. **拆分模块**：每个 `## 模块` 标题下的内容可复制到独立笔记，文件名与 `[[]]` 中的链接保持一致（例如 `一、FineReport 基础与安装部署.md`）。
3. **建立双链**：模块间已通过 `[[]]` 链接，拆分后自动形成知识图谱。
4. **添加标签**：可根据需要为每个模块笔记添加 YAML frontmatter，如 `tags: [FineReport, 报表]`。
5. **细化子节点**：可进一步将每个模块下的 `###` 小节拆分为独立笔记，使用 `[[模块名#小节标题]]` 链接。
